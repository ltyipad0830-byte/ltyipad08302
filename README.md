# EduAI - Smart Learning Platform 🚀

AI 기반 스마트 학습 플랫폼(EduAI) 웹 애플리케이션입니다. Tailwind CSS와 Firebase Firestore가 연동되어 있습니다.

## 📁 파일 구조
- `index.html`: 메인 사용자 인터페이스 및 Firebase 연동 스크립트
- `firebase.js`: Firebase 연결 설정 및 Firestore 모듈 내보내기
- `README.md`: 프로젝트 안내서

## 🛠️ 실행 및 배포 방법 (GitHub Pages 또는 로컬)
1. 이 레포지토리를 클론 또는 다운로드합니다.
2. 브라우저 CORS 정책으로 인해 로컬에서 실행 시 **VS Code Live Server** 등의 로컬 서버 환경을 이용해주세요.
3. GitHub Pages를 통해 정적 웹사이트로 간편하게 배포할 수 있습니다 (`index.html`이 루트에 위치하므로 바로 호스팅 가능).
